# Illustration provenance

The current artwork presents generic users preparing for an appointment. Both images were generated with the built-in image-generation tool and visually checked; neither is a screenshot or evidence of clinical outcomes.

- [Product story](assets/visitprep-product-story.png): select records, inspect original sources, and prepare a reviewed agenda. This replaces the former Watch, hydration and walking portrait in the application and submission.
- [Week 6 workflow](assets/visitprep-week6-workflow.png): the same appointment-preparation flow with technical controls and recorded synthetic evaluation results. People are labeled by role rather than personal names.

The [asset notes](assets/README.md) record the generation and edit prompts, evidence boundaries, and saved filenames. Actual product and provider screenshots are linked separately in the [submission](visitprep-submission.md).

The older `assets/pausewell-story.png` file remains as an original historical asset. It is no longer the current product illustration. Its original portrait provenance and edits remain in Git history; the code license does not grant rights to use that person's likeness.
