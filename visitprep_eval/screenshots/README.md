# Authentic UI evidence

All application records shown here are authored fictional fixtures. No screenshot was generated by AI or had result values changed. Browser captures were taken on September 13, 2026.

- `app-workspace.png`: the running private local app, selected fictional records and the requested updated illustration.
- `app-source-citation.png`: clicking a brief citation opens the original medication-list source. This screenshot uses the local extractive run.
- `app-nebius-full.png`: the actual five-record Nebius brief, accepted with 1,343 reported tokens and 4,212 ms provider latency; an eight-passage selection with exact citations.
- `app-observability.png`: local metadata from that accepted request. The application stores no record text or preparation question in these telemetry rows.
- `nebius-usage.png`: genuine Safari Token Factory usage table, cropped to exclude account identifiers, balance and unrelated browser chrome. The native 1,023×768 capture was cropped at x=205, y=185, width=810, height=400 and encoded as PNG. The displayed aggregate was last updated at 04:56 UTC, before the VisitPrep runs, so it corroborates configured-model account usage only. It is **not** the invoice or request-level evidence for these new runs. Token Factory's Observability page was limited to dedicated endpoints; this project uses serverless inference.
- `braintrust-evaluation.png`: the full 29-case live experiment in Braintrust. The 98.28% displayed average is a contract score (PASS=1, WARN=0.5), not clinical accuracy. Its displayed duration is upload bookkeeping, not inference duration. Actual measured HTTP latency is stored on each provider operation.

- `braintrust-trace.png`: the actual authored-synthetic VP-PX-01 request in the private project, including the malicious request and bounded system instruction.
- `braintrust-metrics.png`: that retest operation’s 1,351 tokens, 7,959.376 ms measured provider latency, synthetic-only flag and case ID. The separate 0.0013 s duration is upload bookkeeping. The tiny estimated cost rounds to zero in the UI; use JSON evidence for precision.

The exact new Nebius requests, returned model completions, errors, usage and timings are in [the live case files](../reports/live/cases/) and [the separate reliability retest](../reports/reliability-retest/cases/). Private Braintrust readback receipts are in each report folder. Screenshots complement those records; they do not replace them.
